# Badge

States who manages a listing: "Ficha informativa" or "Publicado por el alojamiento".

- **Provide:** a `span.at-badge` with the text; add `at-badge-owner` for listings managed by their owner.
- Every listing shows exactly one badge, in lists and on its own page.
- Informational: `surface-alt` with `ink-soft`. Owner: `ink` with `on-ink`. The words carry the meaning; color only reinforces it.
- **Don't:** use badges for types, regions or marketing ("Destacado", "Nuevo").
