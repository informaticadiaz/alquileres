# RegionTag

A small swatch and the region's name, marking which region a listing or destination belongs to.

- **Provide:** a `span.at-region-tag` with the region name, and `style="color: var(--region-…)"` for that region. The swatch takes the same color.
- Always the name next to the swatch; never the swatch alone.
- Use in mixed lists (home "Recién sumados") and above a listing's title. Inside a single-region page it is redundant: leave it out.
