# StepList

The three-step "Cómo funciona" explanation on the home page.

- **Provide:** an `ol.at-steps` of `li.at-step`, each with a decorative `span.at-step-num` (`aria-hidden="true"`), an `h3` and a `p`.
- Numbers are used because the content is a real sequence: choose a destination, read the listing, contact the place.
- Keep exactly the steps a traveler takes; the last one states that the site charges no commission and is not part of the booking.
- **Don't:** reuse numbered markers for content that is not a sequence.
