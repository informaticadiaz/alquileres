# Panel

A boxed block beside or below the main content, in two variants: `at-panel-notice` explains, `at-panel-action` leads to the next step.

- **Provide:** a `section.at-panel` plus a variant, with an `h2` (`title` style), a short `p`, and for the action variant one primary `Button` and optional `caption` help.
- **Notice** (`surface-alt`): what an informational listing is, how the showcase works.
- **Action** (`ink` border): on a listing page, the way to the official site or to contact the owner. On a phone it appears before the long content.
- One action panel per page.
- **Don't:** use panels for generic safety tips or marketing, or nest panels.
