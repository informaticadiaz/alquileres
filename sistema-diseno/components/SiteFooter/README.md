# SiteFooter

The bottom of every page: the showcase notice and the site's navigation.

- **Provide:** a `footer.at-footer` with a `p` holding the showcase notice and a `nav aria-label="Principal"` with, in this order: Destinos, Cómo funciona, Ingresar, and "Publicar alojamiento" as a secondary `Button`.
- The notice text is fixed: "Alquileres Temporarios es una vitrina de anuncios: conectamos propietarios y huéspedes, pero no procesamos reservas ni pagos ni intervenimos como intermediarios en la contratación. Todo acuerdo se realiza directamente entre las partes."
- Notice in `body-sm`, `ink-muted`; links in `ink`, each at least `target-min` tall.
- **Don't:** add a language switcher offering "Spanish (Spain)", or split the notice across columns.
