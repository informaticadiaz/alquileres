# Button

The single action style of the site, in three variants: `at-btn-primary`, `at-btn-secondary` and `at-btn-inverse`.

- **Provide:** a `<button>` for in-page actions or an `<a href>` for navigation, with class `at-btn` plus one variant. The label is a verb phrase that says what happens ("Ir al sitio oficial", "Publicar alojamiento").
- **Primary** (`ink` fill, `on-ink` text): the one main action of a screen or panel. At most one per view.
- **Secondary** (`surface` fill, `ink` border): a second action beside a primary, or the footer's "Publicar alojamiento".
- **Inverse** (`surface` fill on an `ink` band): the action inside the owner band.
- Height is at least `target-min`; radius `radius-md`.
- **Don't:** use region colors for buttons, add icons or arrows after the label, or write "Enviar"/"Click acá".
