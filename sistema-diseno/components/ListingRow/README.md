# ListingRow

One accommodation in a list: name, type, badge and the two ways to go on. It never needs a photo.

- **Provide:** `li.at-listing` inside `ul.at-listing-list`, with `.at-listing-main` (a link `.at-listing-name` and `.at-listing-meta` holding the type, a `Badge` and, in mixed lists, a `RegionTag`) and `.at-listing-actions` ("Ver ficha" and, when it exists, "Sitio oficial").
- The name links to the listing page. The type reads as a noun: "Cabaña", "Apart hotel".
- Location appears once and only if the list mixes destinations: "Cabaña en Mina Clavero".
- **Don't:** add generated descriptions, publication dates, view counts or empty image boxes.
